# Карта Астаны

Веб-карта Астаны: 3D-здания, спутник, поиск адресов, маршруты (авто, пешком, вело), анимация маршрута и пошаговые подсказки.

Сайт: https://astana-map.pages.dev

Стек: MapLibre GL JS, OpenFreeMap (данные OpenStreetMap), Photon/Nominatim (поиск), OSRM routing.openstreetmap.de (маршруты), снимки Esri. Хостинг — Cloudflare Pages, обновляется автоматически при каждом изменении в ветке main.
